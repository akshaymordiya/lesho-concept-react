# Lesho frontend

Not started. This directory will hold the production client applications (consumer app, merchant app, admin console).

Before writing code, read in this order:

1. `../docs/00-overview.md` — what the product is and is not.
2. `../docs/01-design-system.md` — the theme. It is fixed; do not restyle.
3. Run `../concept` and click through every screen. It is the visual and behavioural reference.
4. `../docs/04-api-conventions.md` and the relevant file in `../docs/modules/` for the feature you are building.
5. `../docs/07-frontend-tasks.md` — the ordered task list. Work top to bottom.

The prototype in `../concept` uses local mock state. Production screens must keep its layout, wording and honesty labels while replacing mock state with the API described in the docs.
